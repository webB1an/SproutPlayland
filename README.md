# 小芽智趣岛 / Sprout Playland

面向 2～5 岁儿童的微信益智小游戏。拼图玩法采用“完整画面切块”的方式：图片切成 4、9 或 16 块散落在右侧，儿童把碎片拖回左侧底板，靠近正确位置后自动吸附，全部完成后获得鼓励反馈。

视觉采用明亮糖果色、温暖浅木与大尺寸图形按钮。选择页以中央大图为主，左右只放数量与形状图标；游戏页让关卡图片从边缘到边缘铺满完整拼图区域，并直接把满幅图片切成拼块，不额外添加边框或装饰，中心使用纯色凹槽等待碎片逐步填入，右侧碎片自然堆叠。拼块使用由拼齿轮廓生成的连续挤出面片表现 2.5D 厚度，并通过拿起浮起、自动置顶、轻微倾斜和自动吸附表达操作。

## 开发环境

- Cocos Creator 3.8.8
- TypeScript
- 微信开发者工具 2.02.2607161
- 设计分辨率：1334 × 750，手机横屏

## 本地启动

1. 启动 **Cocos Creator 3.8.8**。
2. 在项目管理器中打开项目目录：

   ```text
   D:\Personal\SproutPlayland
   ```

3. 在 Cocos 的资源管理器中双击打开：

   ```text
   assets/scenes/Main.scene
   ```

4. 按 `Ctrl + P`（或点击编辑器顶部的预览按钮）启动浏览器预览。
5. 默认预览地址为：

   ```text
   http://localhost:7456/
   ```

该地址依赖 Cocos 的预览服务，关闭编辑器或停止预览后将无法访问。

## 日常开发与调试

主要业务代码位于：

```text
assets/scripts/App.ts
```

美术资源位于：

```text
assets/resources/art
```

首页插画、关卡缩略图和拼图源图必须作为三种独立用途管理，不能因为替换某一关的图片而改动首页。当前首页使用 `home-island.png`，第一关拼图使用 `home-island-fullscene.png`。

拼图系统不要求源图预先做成正方形，也不依赖图片四周透明。所有关卡图和用户上传照片都经过同一套显示规则：

1. 保留原图宽高比；
2. 以拼图正方形区域为目标做居中 `cover` 裁切；
3. 再从同一张标准化画面中生成 4、9 或 16 个拼块；
4. 透明 PNG 的透明区域显示关卡配置的兜底底色；
5. 禁止把横图或竖图直接拉伸为正方形。

拼图板只能使用一张原图，不得额外叠加彩色画框或装饰层。原图等比裁切后铺满整个拼图板，并从同一张画面中分割出“最外圈图片边框”和“中央可拖动拼块”：外圈保留原图最外侧像素并固定在底板上，中央区域切成 4、9 或 16 块。全部完成后，外圈与中央拼块必须像素连续、无缝还原成原始完整画面。拼块吸附到外圈时，连接边使用与拼块之间相同的轻微暗缝和高光，但不得增加额外厚度或重阴影。完整图片外圈使用较大的圆角，中央拼图区使用相匹配的较小圆角；只有整幅拼图四个最外角的拼块带圆角，内部拼块连接保持严密，禁止给每个拼块单独削角而产生缝洞。内置关卡和用户上传照片使用同一规则。

微信自定义照片接入时，先通过微信选图接口取得图片并转换为 Cocos `SpriteFrame`，再调用 `SproutPlaylandApp.useCustomPuzzlePhoto(frame, title)`。该入口只更新当前拼图的预览与切块源，不会修改首页插画。

每次修改后的推荐调试流程：

1. 保存代码或资源文件。
2. 等待 Cocos 编辑器右下角的“编译项目脚本”或资源导入提示结束。
3. 回到浏览器，按 `Ctrl + F5` 强制刷新预览页面。
4. 操作游戏，重点检查横屏布局、拖拽、堆叠、吸附和完成动画。
5. 打开浏览器开发者工具，检查 Console 是否有报错。

Cocos 的网页预览并非所有改动都能稳定热更新。如果刷新后仍是旧效果：

1. 回到 Cocos Creator。
2. 按一次 `Ctrl + P` 停止当前预览。
3. 再按一次 `Ctrl + P`，重新编译并启动预览。
4. 在新打开的页面中查看；必要时再按 `Ctrl + F5`。

不要直接修改以下目录，它们是 Cocos 自动生成的缓存或构建产物：

```text
temp/
library/
build/
```

如果网页仍加载旧代码，可先确认 Cocos 已完成编译，再重启场景预览。通常不需要手动运行 TypeScript 编译命令。

## 微信小游戏构建

1. 先在浏览器预览中确认主要交互正常。
2. 打开 Cocos Creator 的“项目 → 构建发布”。
3. 发布平台选择“微信小游戏”。
4. 确认屏幕方向为横屏，设计分辨率为 `1334 × 750`。
5. 点击“构建”，构建目录使用默认的：

   ```text
   build/wechatgame
   ```

6. 构建完成后，点击“运行”或使用微信开发者工具导入该目录。

## 微信开发者工具调试

1. 打开微信开发者工具。
2. 导入 `build/wechatgame`。
3. 点击“编译”查看模拟器效果。
4. 修改代码后，先回到 Cocos Creator 重新执行“构建”，再回微信开发者工具点击“编译”。
5. 使用真机调试检查触摸手感、横屏方向、字体、性能和不同屏幕比例。

浏览器预览适合快速开发；微信开发者工具用于检查微信运行环境、包体和真机表现。

## 常见问题

- **页面没有变化**：等待 Cocos 编译完成，然后按 `Ctrl + F5`；仍无变化时用 `Ctrl + P` 重启预览。
- **图片仍是旧版本**：等待资源导入结束并重启预览，避免直接覆盖 `temp` 或 `library` 中的文件。
- **无法访问 `localhost:7456`**：确认 Cocos Creator 正在运行，并且已经启动场景预览。
- **微信工具里没有最新效果**：浏览器预览的更新不会自动同步到微信构建，需要在 Cocos 中重新构建微信小游戏。

第一阶段不使用登录、网络服务、广告、支付或第三方统计 SDK。
