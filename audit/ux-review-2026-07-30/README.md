# 拼图游戏体验审查（2026-07-30）

## 范围

实际走查：首页 → 拼图列表 → 拼图设置 → 4 块拼图 → 错误放置 → 视觉完成状态。

测试视口：Cocos Creator 的 Apple iPhone 14 Pro 横屏预览。

## 总体判断

首页和设置页已经形成了适合儿童的无文字主交互，图标、颜色和大按钮都比较直观。当前更值得继续观察的是待拼区打乱程度、卡住时的无文字帮助和真机资源占用。

## 流程与健康度

1. 首页：良好。三个入口靠图形即可区分，主视觉柔和。
2. 拼图列表：基本良好。卡片一致、图片主体明确；未获得星星的紫色状态容易被误认为已经获得。
3. 拼图设置：良好。4/9/16 与三种形状都能靠图形理解，选中状态清晰。
4. 拼图开始：基本良好。左侧外露的完整图片边缘是面向儿童的有意提示，应保留；右侧四块在空间上仍较接近一张完整图片，可继续观察是否降低了寻找和观察的乐趣。
5. 错误放置：良好。拼块会停留在放下位置，没有惩罚；但散落后可能覆盖拼图区，需要更清楚的层级和引导。
6. 最后一块尝试：待确认。截图中最后一块只是视觉上靠近槽位，仍然可移动，说明它没有被判定为正确吸附；因此没有出现星级完成弹层属于正常结果，不能据此判断完成逻辑存在故障。

## 建议优先级

### P1

- 加大待拼区的随机偏移，避免四块在右侧仍近似拼成整图。4 块模式应保证相邻的原图碎片不会恰好相邻摆放，并增加轻微但可读的随机旋转。
- 增加无文字的“卡住帮助”：连续 8–12 秒没有有效操作时，让一个拼块轻轻浮动，并让对应槽位短暂呼吸高亮；操作后立即停止。
- 未获得星星使用浅色空心状态，获得后使用黄色实心状态。不要让紫色实心星星看起来像已完成。

### P2

- 首页增加家长可发现、儿童不易误触的音量开关，并记住设置。
- 返回按钮在真机上至少保持约 48–56 px 的可触摸区域，图标可以保持当前大小。
- 不要在启动时一次性加载整个 `resources/art`。当前拼图图片文件约 23.8 MB，建议首页只加载通用资源，进入拼图列表后再分批加载缩略图，进入关卡时只加载当前大图。
- 给 Canvas 交互补充可访问名称或等价操作层；当前浏览器语义树无法识别游戏内按钮，键盘和辅助技术无法操作。

## 证据限制

- 本次只验证了 4 块常规拼图，没有成功完成最后一块，因此没有验证星级完成弹层；也没有完整测试 9/16 块、异形拼图、窄屏适配、低性能安卓机、音效响度与触摸多点并发。
- 截图无法证明颜色对比度、帧率、内存峰值和真机触摸命中率，仍需要真机测试。
