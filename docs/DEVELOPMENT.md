# 开发约定

## 首版范围

- 首页与“拼图岛”入口
- 完整图片切成 4、9、16 块
- 左侧拼图底板与右侧碎片区
- 拖拽、回弹与自动吸附
- 完成反馈
- 返回首页与重新开始

## 产品原则

- 不依赖识字
- 所有内容只要能用图形、颜色、动画或声音表达，就优先用这些方式代替文字。
- 默认玩家不识字；文字只能作为家长辅助说明，不能成为理解页面或完成操作的必要条件。
- 数量选择必须同时显示对应数量或结构的图形，例如 4、9、16 块分别显示 2×2、3×3、4×4 拼图网格。
- 玩法和状态必须有直观图标，例如旋转使用旋转箭头、开始使用播放三角形、选中使用颜色和圆点共同反馈。
- 每个关键操作即使遮住文字，也应能仅凭图形、位置和颜色被理解。
- 拼图游戏页参考儿童拼图产品的“左底板、右碎片”结构；碎片使用原图局部，不用文字命名碎片。
- “拼图框”仅指满幅关卡图片最外圈的拼块区域，不是独立视觉元素。原图必须从边缘到边缘铺满整个拼图矩形，并直接按拼齿切成 4/9/16 块；禁止缩小图片、留白、填充纯色边、添加木框、框线、彩旗或其他装饰。底板只能保留与橙色凹槽同色系的窄定位边，不能预先出现独立拼图框。
- 待拼碎片在右侧采用轻微旋转、相互遮挡但仍可辨认的自然堆叠，触摸后自动置顶。
- 拼图内部边必须成对生成：一块为凸齿时，相邻块必须使用完全互补的凹槽；图片、厚度、描边和阴影都应跟随真实拼齿遮罩，不能只在方形图片上绘制拼齿线。
- 拼块和拼图区不使用白色、橙色等有色轮廓线。待拼拼块必须使用由同一拼齿轮廓采样生成的连续挤出面片表现 2.5D 厚度，所有侧面使用统一的右下投影方向；固定视角下只渲染右侧和下侧可见实体面，上侧和左侧不得生成浅色包边，禁止沿四边外法线向四周扩张形成描边圈；拿起时只适度增加接触阴影距离，避免远距离大投影。
- 拼块归位后逐边控制挤出侧面：与拼图框接触的外边、与已归位拼块衔接的共享边隐藏侧面；只有朝向尚未归位拼块的开放拼齿边保留由窄亮上缘、木质中层、底部暗层和柔和接触阴影组成的清晰厚度。已衔接的共享边只由显示层级较高的拼块绘制一次清晰但轻薄的压合接缝，避免被相邻拼块遮挡，也不能重复绘制形成黑边。
- 拼块吸附落下时，整块投影必须在落下动画中平滑渐隐，并提前显示仍未连接边的局部厚度；禁止在吸附结束的单帧中切换立体状态，也不要使用明显的缩小再回弹效果。
- 相邻开放边的挤出面片必须共享相同的曲线采样端点，保证两个拼块角点处连续，不能露出底板形成假缺口。
- 游戏进行中只保留返回、帮助等必要图标，不显示大段玩法说明。
- 拼图设置页的块数、玩法和开始操作只使用图标表达；中央预览区只展示图片与切割效果，不放标题或说明文字。
- 点击和拖拽区域足够大
- 错误操作没有惩罚
- 不使用倒计时
- 即时声音或动画反馈
- 默认离线，不收集儿童数据

## 代码结构

- 页面流程与拼图底层能力必须分离。
- `scripts/app/App.ts` 只负责页面组装、导航、资源加载和跨页面事件接线，不能重新承载页面 UI、拼齿算法或拖动状态机。
- 当前只保留拼图玩法，拼图的配置、类型、算法、渲染和控制器必须聚合在 `scripts/games/puzzle/` 下。
- 拼图数据类型统一放在 `games/puzzle/PuzzleTypes.ts`，关卡与默认参数统一放在 `games/puzzle/PuzzleConfig.ts`。
- 拼齿和圆角路径统一由 `games/puzzle/PuzzleGeometry.ts` 生成，禁止页面自行复制拼齿计算。
- 2.5D 厚度统一由 `games/puzzle/PuzzleDepthRenderer.ts` 渲染，禁止为单独页面另写阴影或厚度规则。
- 拖动、回弹、吸附、连接边显隐统一由 `games/puzzle/PuzzleInteractionController.ts` 管理。

## 资源结构

- 首页和通用 UI 资源放在 `resources/art/common/`，并按首页、通用图标、通用反馈等用途细分。
- 启动阶段只加载首页与必要的通用 UI；游戏大图必须在进入对应游戏后按目录加载，禁止恢复为启动时 `loadDir('art')` 全量加载。
- 拼图与页面短音效统一放在 `resources/audio/common/`，通过 `app/GameAudioController.ts` 加载和播放。
- 家长自定义鼓励语音统一由 `app/CustomVoiceController.ts` 管理。微信小游戏录音保存在本地用户目录，浏览器预览保存在 IndexedDB；没有录制对应事件时必须静默，禁止自动回退到内置真人语音。
- 自定义语音设置 UI 统一放在 `app/pages/VoiceSettingsPage.ts`，游戏页面只能触发 `correct`、`retry`、`complete`、`star1` 等语音事件，不能自行访问录音和文件接口。
- 调整通用音效后运行 `node tools/generate-game-audio.mjs` 重新生成 WAV 文件，避免在多个游戏中维护重复资源。
- 拼图图片、拼图图标和拼图专用资源统一放在 `resources/art/games/puzzle/`。
- 移动 Cocos 资源时必须同时保留对应 `.meta` 文件，避免 UUID 变化导致场景引用丢失。
