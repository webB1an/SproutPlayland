# 新增小游戏验证记录

## 已完成的自动验证

- TypeScript 5.8.3 严格模式静态检查通过；
- 开启 `noUnusedLocals` 与 `noUnusedParameters` 检查通过；
- 使用 Cocos API 模拟层完成页面构建烟雾测试；
- 对简单、中等、较难三个关卡区间分别模拟完成：
  - 擦除云朵直至触发完成；
  - 拖拽全部图片到对应目标；
  - 连续找到三个正确泡泡；
  - 翻开并配对全部卡片；
- 四种玩法均能生成统一完成弹窗。

## Cocos Creator 中必须复核

当前自动执行环境不包含 Cocos Creator 3.8.8，以下项目需要在 Creator Web Preview 和微信真机中检查：

1. 首页五张卡片在 1334×750、18:9、19.5:9 横屏下是否完整；
2. 默认字体是否能正确显示返回、重玩和下一关符号；
3. 擦擦发现的云朵遮挡是否足够连续，触摸移动事件在真机上是否顺滑；
4. 恐龙归位中 3 张卡片的拖拽范围、自动吸附距离与小屏间距；
5. 泡泡漂浮 Tween 与点击 Tween 叠加时是否有闪跳；
6. 翻牌过程中快速多点触摸是否仍保持锁定；
7. 返回选关后，旧页面 Tween 是否全部停止；
8. 首次进入任一新增玩法时，`art/games/puzzle` 加载时间与内存；
9. 完成弹窗是否只出现一次，重玩和下一关是否正确重置状态；
10. 自定义鼓励语音、短音效和系统静音状态。

## 建议真机顺序

1. 先测试每个玩法的第一关；
2. 再测试第 6 关和最后一关，覆盖三档难度；
3. 每局中途按返回并立即进入另一玩法，检查异步回调；
4. 连续完成 10 局，观察内存与节点数量；
5. 清理小游戏缓存后重新进入，检查进度初始化。
