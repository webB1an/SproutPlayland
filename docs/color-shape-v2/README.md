# 小芽智趣岛：颜色与形状玩法 V2

本分支用于重构 `SproutPlayland` 的颜色与形状玩法，不修改拼图模块。

## 已完成

### 颜色玩法：颜色唤醒

- 不再固定为森林苹果送达；不同关卡会真正使用各自主题、操作物和色板；
- 正确目标按需发光，不再常驻显示整条答案路线；
- 颜色之外增加形状/纹理辅助标记，降低只依赖色相判断的问题；
- 正确操作会立即上色、弹跳并点亮进度，错误操作不扣分；
- 不同主题具有漂浮、游动、弹跳、绽放、摇摆或滚动等完成演出。

### 形状玩法：积木造物

- 移除固定乌龟部件，改用圆形、方形、三角形、长方形、椭圆形等几何积木搭建作品；
- 关卡包括机器人、火箭、帆船、蝴蝶、花朵、房子、小鱼、汽车、城堡和派对笑脸；
- 一星 4 块、二星 6 块、三星 8 块，并逐步减弱提示和增加初始角度；
- 同类部件支持互换，例如左右轮胎、眼睛和翅膀；
- 完成后根据主题播放升空、开走、游动、飞行、跳舞或绽放等动画。

### 共用架构

- `MatchItemState` 与 `MatchTargetState` 已拆分；
- 拖动物会寻找最近的未占用兼容目标，而不是写死唯一目标；
- 颜色、形状和后续颜色+形状组合可继续复用同一交互控制器；
- 列表、星级进度、声音、提示和奖励弹窗继续复用现有公共模块；
- 新关卡主要通过 `ColorConfig.ts` 与 `ShapeConfig.ts` 扩展。

## 本地验证

1. 使用 Cocos Creator 3.8.8 打开项目；
2. 打开 `assets/scenes/Main.scene`；
3. 启动 Web Preview；
4. 依次验证颜色与形状关卡的 1/2/3 星难度；
5. 在微信开发者工具和真机检查横屏、安全区、触摸命中和资源占用。

当前仓库未配置自动 CI；合并到 `main` 前仍需在 Creator 中完成一次实际构建验证。
