# 颜色与形状玩法 V3

本分支面向 3～6 岁儿童，重做颜色和形状玩法的选关、核心交互、场景反馈与奖励 UI。

## 解决的问题

- 选关卡片与实际玩法完全一致，不再用无关插画代替玩法预览；
- 游戏主体由程序完整绘制，不再使用 `cover` 背景裁切关键角色；
- UI 统一为圆润玩具风：厚卡片、木质托盘、糖果按钮、角色表情与弹性动画；
- 形状关直接用圆形、方形、三角形、椭圆形等积木搭建具体物体；
- 每次正确操作都立即改变场景，完成后播放主题演出。

## 色彩魔法

四个精品主题：

1. 气球派对：让灰色气球恢复颜色，完成后一起飞起；
2. 果园丰收：给果实上色，完成后果实欢快弹跳；
3. 海底朋友：给小鱼穿上新衣，完成后鱼群游走；
4. 彩虹火车：点亮彩色车厢，完成后火车开走。

颜色同时配有圆点、条纹、星星、波浪和爱心等辅助纹理，不只依赖色相。

## 形状造物

四个精品主题：

1. 火箭工坊；
2. 快乐小汽车；
3. 温暖小房子；
4. 花园蝴蝶。

选关卡片和游戏目标共用同一份 `parts` 配置，因此预览、拼装目标和最终作品保持一致。难度分别使用 4、6、8 个部件，并逐步降低轮廓提示、缩小吸附范围和增加初始角度。

## 扩展方式

- 新颜色关主要追加 `ColorLevelConfig`；
- 新形状关主要追加 `ShapeLevelConfig.parts`；
- 选关页、拖拽、吸附、错误回位、提示、三星进度、奖励弹窗和完成动画继续复用；
- 大多数积木和场景装饰使用 Cocos `Graphics` 动态绘制，无需为每种颜色复制 PNG。
