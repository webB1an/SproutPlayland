# V3 验证记录

## 已完成

- TypeScript 5.8.3 `strict`、`noUnusedLocals` 静态检查通过；
- 四个颜色选关预览由对应 `sceneKind` 绘制，与游戏场景一致；
- 四个形状预览和游戏目标共用同一份 `parts` 配置；
- 游戏页不再依赖整张主题图 `cover` 铺满，因此不会裁切关键主体；
- 一星颜色模式只显示一个待操作颜料，并修复隐藏颜料仍可能被命中的问题；
- 同类形状目标支持互换，例如左右轮胎、窗户、翅膀和尾翼；
- 新进度使用 `color-stars:v3` 与 `shape-stars:v3`，避免旧版星级直接跳到高难度。

## 仍需 Cocos Creator 验证

2. 4、6、8 个形状积木在小屏幕上的托盘间距；
3. 一星颜色关的逐个出现流程；
4. 完成演出与奖励弹窗是否只触发一次；
5. 自定义语音和音效音量；
6. 微信小游戏首次加载颜色/形状模块的耗时与内存。
